# 视频工具箱 — 打包成 exe 说明

## 方式一：一键打包（推荐）

1. 在 **视频工具箱** 目录下双击运行 **`build.bat`**。
2. 等待执行完成，生成的 exe 在 **`dist\视频工具箱.exe`**。

## 方式二：命令行手动打包

在 **视频工具箱** 目录下打开终端，依次执行：

```bash
# 1. 安装依赖
pip install -r requirements.txt
pip install pyinstaller

# 2. 打包（必须加 --additional-hooks-dir=. 以包含 tkinterdnd2 的 tkdnd 库）
pyinstaller --noconfirm --clean video_tools.spec
```

或不用 spec，直接一条命令（需在当前目录执行，以便使用 hook）：

```bash
pyinstaller --noconfirm --clean --windowed --name "视频工具箱" --additional-hooks-dir=. main.pyw
```

## 前置条件

- 已安装 **Python 3**（建议 3.10+）。
- 已安装项目依赖：`pip install -r requirements.txt`。
- 本机可正常运行 `main.pyw`（即先确认程序能跑通再打包）。

## 打包后说明

- **单文件 exe**：`dist\视频工具箱.exe` 为单文件，可直接复制到其他 Windows 电脑使用。
- **运行环境**：对方电脑不需要安装 Python，但若程序里用到了 **ffmpeg** 做视频处理，需在系统 PATH 中已安装 ffmpeg。
- **杀毒软件**：部分杀毒可能误报，可添加信任或改用“目录模式”打包（见下）。

## 若单文件 exe 报错或想减小体积

可改为“目录模式”打包（生成一个文件夹，内含 exe + 一堆 dll）：

在 `video_tools.spec` 里把最后的 `EXE(...)` 改成先用 `COLLECT` 再生成目录版 exe，或直接命令行：

```bash
pyinstaller --noconfirm --clean --windowed --name "视频工具箱" --additional-hooks-dir=. --onedir main.pyw
```

输出在 `dist\视频工具箱\` 目录下，运行其中的 `视频工具箱.exe`。

## 文件说明

| 文件 | 说明 |
|------|------|
| `requirements.txt` | 项目 Python 依赖 |
| `video_tools.spec` | PyInstaller 打包配置（入口为 main.pyw） |
| `hook-tkinterdnd2.py` | 让 tkinterdnd2 的拖拽库正确打进 exe |
| `build.bat` | 一键执行依赖安装 + 打包脚本 |
